# Images

Drop two photos here:

- `profile.jpg` — circular avatar shown in the hero (the Corona Sunsets concert photo).
  Recommended: 600&times;600 or larger, square crop.
- `hero-bg.jpg` — full-bleed poster background for the hero (the sunset / hillside photo).
  Recommended: 2000&times;1200+ landscape, JPEG ~300&ndash;800 KB.

Both are referenced from `index.html` and `css/site.css`. The site degrades gracefully if either file is missing (avatar hides, background falls back to dark).
