Flagship

Sim ↔ Real validation

Digital Twin for Simulation-to-Real Validation

Isaac Sim · PhysX · ros2_control

Designed a high-fidelity digital twin to enable reliable simulation-to-real validation of robot behaviour — aligning kinematics, dynamics, sensing and control between simulated and physical systems.

  • Modelled complex physical interactions and validated control and safety pipelines under real-time constraints.
  • Built an equivalence framework that turns simulation into a reproducible source of truth for system behaviour.

Why it matters Enables simulation to be used as a reliable testing environment before real-world deployment.

Distributed systems · Real-time

Distributed HIL System — Isaac Sim + Dual Orin

Isaac Sim · Dual Jetson Orins · ROS 2

Designed a distributed hardware-in-the-loop system that replicates the real robot's compute and network architecture — Isaac Sim driving a dual-Orin edge stack across a production-grade interconnect.

  • Built pipelines for sensor emulation, communication, and synchronisation across machines.
  • Sustained high-bandwidth data streams under real-time constraints with bounded end-to-end latency.

Why it matters Allows full-stack validation under production-like constraints before hardware deployment.

Supporting

Motion planning · Design evaluation

Tool Coverage & Design Evaluation Pipeline

MoveIt 2 · IK · Collision checking

Built a pipeline to evaluate robot design feasibility by computing tool coverage across large-scale construction site geometries — turning hardware iterations into measurable deltas instead of intuition.

  • Generated dense pose sets and validated feasibility through inverse kinematics, collision checking, and task constraints.
  • Aggregated results into quantitative coverage metrics that surface design limitations and guide iteration.

Why it matters Provides quantitative metrics to guide robot design and deployment feasibility.
